부스 게임 3종 — 실행 방법과 운영자 안내
==========================================

[실행]
1. 폴더를 통째로 PC에 복사합니다 (zip이면 먼저 "압축 풀기").
2. index.html 을 Chrome으로 엽니다 (더블클릭, 기본 브라우저가 Chrome이 아니면
   파일을 Chrome 창에 끌어다 놓기).
3. F11 을 눌러 전체 화면으로 만듭니다.

  * 인터넷이 없어도 됩니다. 설치할 것도 없습니다.
  * 시크릿 창(InPrivate)에서 열지 마세요. 순위가 저장되지 않습니다.
    (시크릿 창이면 시작 화면 아래에 빨간 경고가 나옵니다.)
  * 순위는 "이 PC의 이 브라우저"에 저장됩니다. 폴더 위치를 바꾸면 순위가
    따로 저장되므로, 행사 당일에는 같은 폴더에서 계속 실행하세요.

[게임]
  1 과일 받기   ← → (또는 A D)        60초, 폭탄 3번이면 끝   초등 추천
  2 우주 방위대 방향키 (또는 W A S D)  총은 자동, F 폭탄, 마지막에 보스
  3 2인 대전    1P: W A S D + F        2P: U H J K + L
                0 을 누르면 혼자서 컴퓨터와 대전

[운영자 단축키]
  M                      소리 켜기/끄기 (오른쪽 위에 음소거 표시)
  Esc 2초 누르기          처음 화면(게임 고르기)으로
  Shift + Delete 3초     지금 게임의 순위 초기화 (순위표 화면에서만 동작)
                         - 과일 받기 / 우주 방위대 시작 화면에서 10초 기다리면
                           순위표가 나옵니다. 그때 누르세요.
  T (처음 화면에서)       키 동시 입력 테스트

  * 아무도 안 만지면 15초 뒤 자동으로 시작 화면으로 돌아갑니다
    (게임 중에는 돌아가지 않습니다).
  * 2인 대전 결과 화면: R 다시 하기 / Esc 처음으로 / 10초 지나면 처음으로

[행사 전 확인: 키보드]
  2인 대전은 키 6개를 동시에 누릅니다. 키보드에 따라 일부 조합이 씹힐 수 있어요.
  1. 처음 화면에서 T 를 눌러 키 테스트를 엽니다.
  2. 두 사람이 1P 칸 3개, 2P 칸 3개를 동시에 누릅니다. 6칸이 모두 초록이면 "합격".
  3. 2인 대전 키는 고정입니다.
       1P: 이동 W A S D / 던지기 F
       2P: 이동 U H J K / 던지기 L
  4. 합격이 안 되면 2인 대전용으로 외장 키보드를 하나 더 연결하세요.

[난이도 조정]
  각 게임 파일(fruit.html, shooter.html, versus.html)을 메모장으로 열면
  맨 위에 "const CONFIG = {" 가 있습니다. 숫자만 바꾸고 저장한 뒤 F5.
  어떤 값을 바꿀지는 기획 문서의 "조정 순서" 표를 보세요.
    과일 받기: 01-fruit-plan.md §10
    우주 방위대: 02-shooter-plan.md §8
    2인 대전 : 03-versus-plan.md §12
  2인 대전 방패 아이템을 끄려면 versus.html 의 item: { enabled: true ...} 를 false 로.

[파일]

  core.js       세 게임 공통 기능
  fruit.html    과일 받기
  shooter.html  우주 방위대
  versus.html   2인 대전
  keytest.html  키 동시 입력 테스트
